aMazeControlPlane

Stop your AI agents from burning money — or doing something worse.

aMazeControlPlane is an open-source AI agent control plane for MCP, A2A, and LLM traffic. Enforce runtime policies, govern tool access, cap token and call budgets, protect PII, and audit agent behavior from one independent layer — without changing your agent code.

View on GitHub → Get started
One control plane for agent policies, MCP tool calls, token budgets, A2A interactions, alerts, and traces.
Runtime governance

The agent proposes.
The control plane decides.

Agent frameworks orchestrate behavior. aMazeControlPlane sits on the execution path and independently decides what agents are allowed to do before actions reach MCP servers, A2A agents, or LLM providers.

🛡️

Runtime policy enforcement

Allow, block, or constrain actions using agent identity, tool, arguments, budgets, and runtime context.

🔧

MCP tool governance

Control which MCP tools are visible and callable per agent, with argument-level policy enforcement.

🔗

A2A governance

Observe and govern agent-to-agent interactions instead of treating delegated agents as implicitly trusted.

💸

Budgets & runaway protection

Cap tokens, calls, retries, and loops independently of the agent's own logic.

🔐

PII protection

Detect and redact sensitive data at the control-plane boundary before it crosses a trust boundary.

🧾

Audit & traces

Record not only what happened, but which policy evaluated the action and why it was allowed or blocked.

Architecture

A framework-independent enforcement boundary

LangGraph, OpenAI Agents SDK, CrewAI, custom agents, and other runtimes can share the same external governance layer.

AI Agent / Agent Framework │ │ proposes LLM / MCP / A2A action ▼ aMazeControlPlane │ ├── Agent identity ├── Runtime policy ├── Tool + argument authorization ├── PII protection ├── Token / call / retry budgets └── Audit + traces │ │ authorized action ▼ MCP Server / A2A Agent / LLM Provider
